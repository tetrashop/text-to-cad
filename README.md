## 📝 Abstract (چکیده علمی)
The "Semantic Gap" between human intent (text/images) and precise parametric CAD modeling is a major bottleneck in modern engineering. **Text-to-CAD & Vision-to-CAD** is a fully deployed, cloud-native application that leverages Multimodal Large Language Models (MLLMs) to bridge this gap. 

Initially starting as a simple text-to-script parser, the project evolved through multiple architectural iterations to solve critical serverless limitations. The final architecture utilizes a **decoupled cloud infrastructure**: a Next.js/HTML frontend hosted on Vercel, and a Dockerized Python/FastAPI backend hosted on Render. The backend utilizes headless OpenSCAD to execute Constructive Solid Geometry (CSG) operations generated by Vision-Language Models (like Qwen-VL), successfully translating 2D engineering blueprints and Persian natural language into downloadable 3D STL meshes.

---

## 🏗️ 1. System Architecture (معماری سیستم)
The system is designed with a highly decoupled, cloud-native microservices architecture to separate user interaction from heavy geometric computation.

*   **Frontend (Vercel):** Handles UI/UX, image compression (via HTML5 Canvas to reduce payload size and prevent network timeouts), and 3D rendering using Three.js.
*   **Backend API (Render):** A FastAPI server running inside a custom Docker container.
*   **CAD Engine (Docker Container):** Since Serverless platforms (like Vercel) do not allow native binary execution, the backend runs in a Linux environment equipped with **OpenSCAD** and **Xvfb** (for headless rendering without a physical display).
*   **AI Core (OpenRouter):** Uses open-source Vision-Language Models (e.g., Qwen VL, Llama 3) via OpenRouter API to parse the input and generate raw OpenSCAD scripts.

## 🔬 2. Engineering Methodology & Iterations (روش‌شناسی و تکامل پروژه)

### Phase 1: The OpenSCAD Serverless Failure (نسخه اولیه)
Initial attempts used a Vercel-only architecture where the AI generated OpenSCAD code directly in the browser.
*   **Failure Analysis:** Vercel Serverless functions timed out during complex Boolean operations. Furthermore, raw LLMs demonstrated severe "Spatial Reasoning Deficits" — they frequently failed to translate basic primitive combinations (e.g., placing a cone on a cylinder or subtracting a through-hole) into correct Z-axis coordinates. 

### Phase 2: Dockerization & Headless Rendering (راه‌حل زیرساختی)
To fix the timeout and native execution issues, a dedicated cloud server was introduced.
*   **Solution:** A `Dockerfile` was created based on `python:3.11-slim`, installing `openscad`, `xvfb`, and `libgl1`.
*   **Xvfb (X Virtual Framebuffer):** Crucial for executing OpenSCAD in a headless server environment. A wrapper script (`openscad-headless`) was implemented to trick OpenSCAD into running without a GPU/Display.
*   **Deployment:** The FastAPI backend was deployed on **Render** (using the Docker runtime), solving the execution limits.

### Phase 3: Multimodal Integration (Vision-to-CAD)
The system was upgraded from text-only to image-to-3D.
*   **Image Preprocessing:** The frontend compresses uploaded blueprints to a maximum width of 600px and converts them to JPEG Base64, ensuring fast transmission.
*   **Vision-Language Models (VLM):** The backend was modified to accept Base64 images. The AI is instructed to analyze dimensions, views (front, top, side), and annotations on the engineering drawing, and subsequently write the corresponding OpenSCAD CSG code.

## 🧪 3. Empirical Testing & Success Case (نتایج تست‌ها)
*   **Test 1 (Text):** Generating a 40x40x40 cube with a 15-radius through-hole. **Result:** Successful (Self-healing loop corrected initial syntax errors).
*   **Test 2 (Vision):** Uploading a 2D blueprint of a standard mechanical plate (100x100mm with one R20 central hole and four R5 corner holes). **Result:** The VLM accurately recognized the geometry and the OpenSCAD engine rendered a precise 3D STL mesh in the browser.

## 🛠️ 4. Technology Stack (تکنولوژی‌ها)
*   **Frontend:** HTML5, JavaScript, Three.js, Canvas API (Image Compression)
*   **Backend:** Python 3.11, FastAPI, Uvicorn, Pydantic
*   **Infrastructure:** Docker, Vercel, Render
*   **CAD Engine:** OpenSCAD (Headless)
*   **AI:** OpenRouter API (Llama-3, Qwen-VL)

## 🚀 5. Local Setup & Installation (راه‌اندازی محلی)
*(Note: Requires Python 3.11 and OpenSCAD installed on your system)*
```bash
# Clone the repository
git clone https://github.com/tetrashop/text-to-cad.git
cd text-to-cad

# Setup backend
cd backend
pip install -r requirements.txt
export OPENROUTER_API_KEY="your_api_key_here"
uvicorn main:app --host 0.0.0.0 --port 8000

# In a new terminal, serve the frontend
cd frontend
python -m http.server 8080
```

(Open http://localhost:8080 in your browser).
